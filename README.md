# SomosAstros

App web (React + Vite) para comparar dos cartas natales: aspectos entre planetas, overlays (planetas de uno en las casas del otro), cruces con Asc/MC, dimensiones y escenarios. Pegás el texto del informe (por ejemplo de [Los Arcanos](https://www.losarcanos.com/carta-astral-2.php)) o cargás un PDF con texto seleccionable.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Aviso

Herramienta orientativa y educativa, no sustituye consejo profesional de salud, legal o psicológico.
